($250 prize pool, entries close 19 November 2026 00:00 UTC).

One image sums up Tuesday 17 November 2026: a tanker burning in the Strait
of Hormuz in the foreground, the collapsed Kerch Bridge behind it, and the
failing Vulcan rocket breaking apart in the sky — with the date and one short
caption per story. `main.ts` (Node 22, standard library only) copies
`entry.png` to `/output/entry.png`, deterministically, on every run.

Run it: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`
